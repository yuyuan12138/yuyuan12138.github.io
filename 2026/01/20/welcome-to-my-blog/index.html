Why Jekyll and GitHub Pages?

I chose Jekyll for this blog because:

  • Simple: No database needed, just Markdown files
  • Fast: Static HTML generation for quick loading
  • Free: GitHub Pages hosting at no cost
  • Version Control: Git-based content management
